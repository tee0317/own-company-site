# 掲載写真と利用条件

2026-10-25、無料素材（Unsplash）の写真をすべて外し、画像生成AI（ChatGPTの画像生成・本人のPlus契約）で作った写真に統一した。世界観と生成の約束は PJClaude の `cases/work/decaf-tea-hp/art-direction.md`、元画像とプロンプトは同じフォルダの `gen/`。

- 写真はすべてイメージ。作り手本人・実際の会場やお客様・販売する茶葉や商品を示すものではない（フッターに明記）
- 人物は手元・後ろ姿・逆光の影のみ。作り手の写真は本人が後日用意し、別人の姿を作り手として使わない
- 「こんな場所で」の4枚は実績ではない。実績を載せる時は「実例」と分けて書く
- 表示用のAVIF/WebPはAstroで生成。altは実際の写りに合わせた
